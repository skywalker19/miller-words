## 每次怎么练

1. 每次练习约 5–8 个词，先读英文短句。词少的场景可以合并，词较多的场景分两次练。
2. 用中文检查理解，再遮住文字复述，或画图、做动作提示回忆。
3. 选两词造新句，并在 [review-log.md](review-log.md) 中记录表现。
4. 首次学习后第 1、3、7、14 天复习；间隔从实际学习日算起。
